# 短视频脚本与分镜清单助手

先想清楚要讲什么、能拍什么，再带着一张镜头清单开工。

适用对象：OPC企业、独立创业者及小型业务团队。中文界面，原生HTML/CSS/JavaScript，MIT开源，无第三方前端依赖。

## 界面预览

![界面预览](preview.png)

## 功能

- 15—300秒时间段分配
- 口播草稿与画面建议
- 设备、道具及拍摄检查清单
- 可选AI脚本创作与文档导出

## 快速开始

**离线使用：** 下载完整仓库后双击 `index.html`，点击“载入示例”，再点击左侧主按钮。

**本地服务：** 在本文件夹运行（Python 3.9或更高版本）：

```bash
python3 server.py
```

打开 `http://127.0.0.1:8765`。端口占用时可用 `python3 server.py --port 8766`。服务只绑定本机。Windows可用 `py server.py`。

## 示例与使用流程

用手机和桌面拍一条60秒便携风扇介绍视频。

1. 载入示例，查看左侧资料。
2. 点击主按钮运行，查看右侧结果。
3. 按实际工作修改输入并重新生成；文档类结果也可点“编辑结果”。
4. 使用导出、专用下载或打印保存成果。页面刷新不保留资料，关闭前请导出。

## 可选AI功能

1. 在本项目文件夹运行 `python3 server.py`，打开终端显示的网址。
2. 点击“模型设置”，填入兼容Chat Completions的地址（通常以 `/v1` 结尾）、模型名和密钥。
3. 点击“AI辅助生成”；资料将通过本机代理发送到你选择的服务商。

密钥只在当前页面内存中保存，不写入文件、浏览器存储或日志。模型服务可能收费；请自行确认服务条款和数据处理要求。没有密钥也能使用本地功能。接口仅适配兼容Chat Completions的服务，不承诺所有供应商可用；静态GitHub Pages不提供AI代理。

## 功能边界

本地为四段分镜模板；不生成视频，口播长度需试读校准。

模板结果、规则整理与AI结果在界面明确区分；业务事实和客户承诺请人工核对。

## 文件结构

- `index.html`：独立入口
- `app.js`：本工具业务逻辑与示例
- `core.js` / `style.css`：页面、交互及通用导出
- `lib.js`：计算、字幕、剧情或ZIP辅助函数
- `server.py`：可选本地静态服务和AI代理
- `examples/`：示例说明
- `LICENSE`：MIT许可证
